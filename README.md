# HTML Portfolio Checkpoint

A beginner portfolio for Marvin, built with semantic HTML and simple CSS. Open index.html directly in a browser, or use VS Code's Live Server. No npm installation is needed.

## Requirements
- header, nav, main, section, article, figure, figcaption, and footer semantic elements.
- Home, About, Work, Resume, and Contact navigation links point to sections on the same page.
- A playable audio element with a bundled original welcome chime.
- Lists in the navbar and skills section.
- A contact form with associated labels, name, email, message, required fields, and a submit button.
- Footer with copyright and a Back to top link.

The contact form is a demo. Browser validation checks the inputs; script.js displays a confirmation without sending or storing messages. A backend or form service would be needed for delivery. The chime is generated audio, not a voice recording. Replace assets/welcome.wav and update the caption if you prefer your own introduction recording.

style.css adds a responsive layout. All required structure is in index.html. The project links refer to Marvin's existing GitHub projects. Prepared with ChatGPT assistance.

The linked layout example could not be fetched in this environment; implementation follows the written checkpoint requirements.
